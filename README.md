# SpendSense — refreshed Pro interface

## Run
1. Extract the ZIP.
2. Open `SpendSense_AI_Pro/index.html` in Chrome or Edge.
3. Choose **Create account** or **Continue with demo account**.
4. No server, API key or install is needed for the demo.

## What's new
- Redesigned editorial/futuristic dark teal interface with a separate sign-in / create-account screen.
- Demo account sign-in and sign-up flows.
- Profile dropdown in the top navigation.
- Profile & settings page: edit display name, email and monthly budget.
- Sign out and remembered local session.
- Per-account local transaction, budget and savings-goal data.
- Dashboard, transactions, budgets, AI insights and savings goals remain interactive.

## Demo login
Use **Continue with demo account**. This enters a sample workspace immediately.

## Important authentication/privacy note
This is a front-end hackathon prototype. Sign-up/sign-in is simulated using browser localStorage; passwords are stored locally in plain text. It is NOT secure production authentication and must not be used with real passwords or sensitive information. A production release requires a backend, password hashing, HTTPS, session management, rate limiting, secure database storage and account recovery.

## AI transparency
Insights are generated by a local explainable rule-based engine from manually entered demo transactions. It is not a live LLM or bank connection. Sample transactions are illustrative.

## Complete sidebar navigation added
Home, Dashboard, Transactions, AI Assistant, Budget Planner, Predictions, Savings Goals, Split Expenses, Analytics, Profile and Sign out. The AI assistant is a local rule-based demo, predictions are a simple daily-spend projection, and split expenses calculates an equal share.
